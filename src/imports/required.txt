# Full-Stack Developer Portfolio

A modern, full-stack developer portfolio platform designed to showcase professional information, technical skills, work experience, projects, and contact information. The platform includes two separate modes: **Viewer Mode** for public visitors and **Admin Mode** for managing portfolio content.

The application is built with **Next.js and NestJS**, backed by **PostgreSQL**, and designed with a cloud-friendly architecture so all components can be deployed using free-tier cloud services during development and personal use.

# 7. API Design

Example REST API:

```text
POST   /api/v1/auth/login
POST   /api/v1/auth/refresh
POST   /api/v1/auth/logout

GET    /api/v1/profile
PATCH  /api/v1/profile

GET    /api/v1/projects
GET    /api/v1/projects/:id
POST   /api/v1/projects
PATCH  /api/v1/projects/:id
DELETE /api/v1/projects/:id

GET    /api/v1/experiences
POST   /api/v1/experiences
PATCH  /api/v1/experiences/:id
DELETE /api/v1/experiences/:id

GET    /api/v1/skills
POST   /api/v1/skills
PATCH  /api/v1/skills/:id
DELETE /api/v1/skills/:id

POST   /api/v1/contacts
GET    /api/v1/contacts
PATCH  /api/v1/contacts/:id
DELETE /api/v1/contacts/:id
```

Public endpoints can be separated from protected admin endpoints:

```text
/api/v1/public/*
/api/v1/admin/*
```

# 8. Cloud-Friendly Deployment

The project should be designed so each component can use free-tier services.

```text
                ┌───────────────────┐
                │      Vercel       │
                │     Next.js       │
                └─────────┬─────────┘
                          │
                          ▼
                ┌───────────────────┐
                │      Vercel       │
                │      NestJS       │
                └──────┬─────┬──────┘
                       │     │
                       ▼     ▼
                PostgreSQL   Redis
                       │
                       ▼
                Neon / Supabase
```

Possible free-tier services:

| Component      | Service                    |
| -------------- | -------------------------- |
| Next.js        | Vercel                     |
| NestJS         | Vercel / Render / Koyeb    |
| PostgreSQL     | Neon / Supabase            |
| Redis          | Upstash                    |
| Images         | Cloudinary / Cloudflare R2 |
| Git Repository | GitHub                     |
| Domain         | Free provider subdomain    |

The architecture should remain **provider-independent**, allowing individual services to be replaced later without changing the entire application.

# Project Goal

The goal is to build more than a traditional portfolio website. It is a **full-stack portfolio CMS** where the public website acts as the presentation layer and the admin dashboard acts as a content management system.

The project demonstrates practical experience with:

**Next.js + React + TypeScript + NestJS + REST API + WebSocket/Socket.IO + PostgreSQL + Authentication + CRUD + Cloud Deployment + Database Design + API Architecture.**

This makes the project suitable not only as a personal portfolio but also as a strong demonstration of full-stack development, backend architecture, authentication, database management, and cloud deployment skills.
